```
└──────────────────┴──────────────────┘
```

### 色彩方案
- 主色: `#667eea` → `#764ba2` (渐变)
- 成功: `#67C23A`
- 警告: `#E6A23C`
- 危险: `#F56C6C`

### 响应式
- 📱 手机 (< 768px): 竖向堆叠
- 📱 平板 (768~1200px): 上下两部分
- 🖥️  桌面 (≥ 1200px): 标准布局

## 📊 核心功能详解

### 模块 1: 图片展示
- 🖼️ 4 种类型图片同时显示
- 📊 异步加载，进度提示
- 📝 标签标识，清晰分类
- 🎨 响应式 2×2 网格

### 模块 2: 目标检测
- 🎯 Canvas 实时绘制
- 🌈 彩色检测框，置信度标签
- 🖱️ 鼠标交互，高亮效果
- 📋 右侧面板显示详情

### 模块 3: 控制面板
- ▶️ 开始/结束处理按钮
- 📈 实时进度条显示
- 🔗 WebSocket 连接状态
- ⚙️ 高级设置面板

### 模块 4: 数据展示
- 📊 统计摘要卡片
- 📋 结构化数据表格
- 🎨 置信度可视化进度条
- 📄 详细信息和原始数据

## 🔗 WebSocket 接口

### 前端 → 后端
```json
{
  "type": "process_request",
  "data": {
    "file_path": "/path/to/image.jpg",
    "params": { ... }
  }
}
```

### 后端 → 前端
```json
{
  "status": "success",
  "timestamp": 1234567890,
  "processingTime": 150,
  "detections": [

      "x": 100,
      "y": 150,
      "width": 80,
      "height": 120,
      "class": "汽车",
      "confidence": 0.92

  ]
```
